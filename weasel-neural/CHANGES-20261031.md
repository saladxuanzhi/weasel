# 本轮修改与待验项目

主分支整合：根 README 重写功能、安装与配置教程。上游致谢合并为一条，新增青简致谢。CI 先从同一源提交构建 x64/x86 DLL，再供 msbuild/xmake 安装包使用。NSIS 在每个服务端架构分支强制包含匹配 DLL。build.bat 和 xbuild.bat 本地打包也会自动编译；CI 复用 DLL 时检查提交、架构与 SHA-256。停止发布独立 p2c-dll，master 更新 p2c-test 安装包。模型权重仍单独放置。

新增打包校验测试，使用临时 PE 头验证成功路径、源提交错误、缺失文件、哈希错误、架构错配及无效文件。已用 PowerShell 在 Linux 执行通过。该测试不等于 Windows DLL 加载或安装器实机验证；后两项由后续构建和 Windows 验收确认。

生成项显示标记：增加 `p2c/marker`（默认 ✦）及 `p2c/marker_position`（prefix/comment/none，默认 prefix）。只修改展示文本，选词状态保留未修饰的生成原文；详细来源标记仍由 show_source 独立控制。示例及个人配置改为星标显示、关闭详细来源注释。默认保持生成第二项，不按不可直接比较的模型 log 概率与 Rime 权重自动改序。需要重新编译 Weasel，Windows 字体和星标显示待实机验收。

分段确认修复：按 Rime composition.preedit/sel_start 获取已选前缀和剩余全拼，严格校验剩余拼音与原始输入末尾一致，光标在中间或无法对齐时不调用模型。门槛 min_keys 只计算剩余输入。请求身份包含已选前缀，前缀改变会取消旧请求；显示前及模型提交前再次核对身份。候选只显示生成的后缀，直接上屏时拼回已确认前缀，避免 clear_composition 丢掉它。选择词库前缀后立即调度剩余部分。此变更不需要替换 Rust DLL，需要重新编译 Weasel。

新增测试覆盖整段拼音、UTF-8 中文已选前缀、剩余 cha、非行内预编辑的软光标、相同后缀而前缀变化、光标在中间、错位拼音、无剩余输入及拼音分隔符。Windows 分段确认和撤销选择仍需实机验证。

第三轮反馈：用户尚未安装改变默认排序的版本，仍观察到第二项更准确。不能仅凭位置判断来源；增加 `p2c/show_source` 诊断开关，标注 Rime 候选、额外生成项及生成结果与 Rime 同文而被去重的候选。默认关闭，示例配置开启。去重路径目前保留原排名，来源标记不会改变这一行为。

第二轮实机反馈：生成结果异步返回后将正确词库句子挤到第二位。现默认 `p2c/prefer_generated: false`，保留词库第一项、生成句补充为第二项；选择与鼠标高亮按生成项的实际插入位置映射。显式设为 true 可恢复生成优先。新增映射测试覆盖两种插入位置及十项候选选择。需要重新编译 Weasel，Windows 实机待验。
